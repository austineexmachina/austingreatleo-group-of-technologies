# Austingreatleo Group of Technologies

A responsive corporate website built with Next.js App Router, TypeScript, Tailwind CSS v4 and custom CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project uses Next.js static export. The build output is generated in `out/`.

## Cloudflare Pages

- Framework preset: Next.js (Static HTML Export) or None
- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `out`
- Node.js: 20 or newer

For a Git-connected Cloudflare Pages project, connect this repository and use the settings above.
